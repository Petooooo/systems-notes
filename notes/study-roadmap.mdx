Data structures, graph traversal, dynamic programming, greedy algorithms, complexity analysis, and problem-solving practice. Solutions and tests live separately in the [GitHub study repository](https://github.com/Petooooo/systems-notes/tree/main/labs/algorithms).

## Systems programming

C/C++, POSIX APIs, process/thread lifecycle, synchronization, IPC, sockets, and file I/O. For each topic, I want to pair conceptual notes with small, reproducible programs.

Revisit relevant undergraduate topics: operating systems, computer architecture, computer networks, databases, and hardware/software interfaces.

## Linux, storage & memory

Focus on kernel execution, VFS and file systems, page cache, block I/O, flash/SSD, NVMe, memory management, and performance analysis.

## Graduate study

As I begin my KAIST master's program in spring 2027, I plan to add course notes and reproducible systems experiments. Research and laboratory material will be shared only when appropriate for public release.
