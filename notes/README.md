# Study notes

These folders distinguish the **subject being learned** from the **code used to practice it**. Runnable programs belong in [labs/](../labs/).

- [Algorithms](algorithms/) — coding tests, complexity, data structures and patterns
- [System programming](system-programming/) — C/C++, POSIX, processes, threads, IPC and networking
- [Undergraduate subjects](undergraduate/) — existing CS and EE course foundations
- [Linux kernel](linux-kernel/) — kernel structures, tracing, scheduling and memory
- [Storage](storage/) — VFS, file systems, flash/SSD, NVMe and I/O
- [Graduate study](graduate/) — new courses, paper reading and original experiments

Use the [note template](_templates/note.mdx). The [study roadmap](study-roadmap.mdx) is a published index.
