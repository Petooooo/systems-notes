# 공부 노트

노트는 **한국어로, 나중에 다시 읽어도 이해할 수 있게** 작성한다. 실행 가능한 코드는 [labs/](../labs/)에 별도로 보관한다.

- [Algorithms](algorithms/) — 자료구조, 복잡도, 풀이 패턴, 오답 정리
- [System Programming](system-programming/) — C/C++, POSIX, 프로세스, 스레드, IPC, 소켓
- [Undergraduate Courses](undergraduate/) — 운영체제, 컴퓨터구조, 네트워크, 데이터베이스, 디지털 회로
- [Linux Kernel](linux-kernel/) — 스케줄러, 메모리 관리, tracing, 드라이버
- [Storage & File Systems](storage/) — VFS, ext4/F2FS, Flash/SSD, NVMe, I/O
- [Graduate Study](graduate/) — 수업 정리, 논문, 연구 준비

새 글은 [일반 노트](./_templates/note.mdx), [알고리즘 풀이](./_templates/algorithm.mdx), [실험 기록](./_templates/experiment.mdx) 템플릿을 복사하여 작성한다. [학습 로드맵](study-roadmap.mdx)은 앞으로의 학습 계획이다.
