## 1. 자료구조를 먼저 선택하는 이유

코딩테스트를 풀 때 코드를 빨리 작성하는 것보다 **문제의 입력 크기와 필요한 연산을 먼저 분리**하는 것이 중요하다. 같은 문제도 배열을 순회하면 O(N)인 연산이 해시를 이용하면 기대 O(1)에 가까워질 수 있다. 반대로 해시가 모든 상황에서 빠른 것도 아니다.

## 2. 시간 복잡도와 입력 크기

| 복잡도 | N이 커질 때 | 대표 패턴 |
| --- | --- | --- |
| O(1) | 입력 크기와 무관한 작업 수 | 인덱스 접근 |
| O(log N) | 입력을 반복적으로 줄임 | Binary search |
| O(N) | 전체 입력 한 번 순회 | Count / two pointers |
| O(N log N) | 정렬·divide-and-conquer | Sorting |
| O(N²) | 이중 순회 | 모든 pair 비교 |
| O(2^N) | 상태 공간이 폭발 가능 | 일부 완전 탐색 |

Big-O는 상한의 점근 표현이다. **숨은 상수, 메모리 접근 패턴, Python 실행 비용** 등 실제 시간도 고려해야 한다.

## 3. 배열과 연결 리스트

배열은 인덱스로 접근하기 쉽지만 중간 삽입·삭제는 원소 이동이 필요할 수 있다. 연결 리스트는 노드 연결 변경으로 삽입이 쉬운 경우가 있지만 **삽입 위치를 찾는 비용**이 별도이며 cache locality가 나쁠 수 있다.

| 요구 | 우선 검토 |
| --- | --- |
| 인덱스 접근이 많음 | Array/vector |
| 끝에 append가 많음 | Dynamic array |
| 앞뒤에서 원소 제거 | Deque |
| 임의 위치 조회 | Index/hash |
| 순회 순서 유지 | Array/list, 요구에 따라 |

## 4. Hash Map과 충돌

Python `dict`, C++ `unordered_map` 등은 키를 해시해 위치를 찾는다. 평균적인 탐색 비용이 낮지만 **최악 시간은 구현과 충돌 패턴에 영향을 받는다**.

Counter나 frequency map이 유용한 문제에서는 먼저 중복을 세어 전체 탐색 횟수를 줄일 수 있는지 검토한다.

```python
def frequency(values):
    counts = {}
    for v in values:
        counts[v] = counts.get(v, 0) + 1
    return counts
```

예제는 개념 설명용이며 시간 측정 기록이 아니다.

## 5. Stack과 Queue

- Stack: LIFO. 괄호 검사, DFS, monotonic stack 등의 패턴.
- Queue: FIFO. BFS, 작업 순서 처리.
- Deque: 양쪽 끝에서 push/pop이 효율적인 자료구조.

Python에서 `list.pop(0)`을 반복하는 방식은 일반적인 Queue 구현으로 부적절할 수 있다. `collections.deque`를 활용한다.

## 6. Space complexity도 확인하기

O(N) 시간 알고리즘이 O(N) 추가 배열을 요구할 수 있다. 입력이 수백만 개인 문제에서 별도의 adjacency matrix를 만들면 메모리가 부족할 수 있다.

- 입력 자체 저장 공간과 추가 공간을 구분.
- 재귀 call stack도 공간 복잡도에 포함.
- 문자열 slicing이나 list copying이 숨은 메모리를 만들 수 있음.
- Python의 객체 overhead는 C++의 primitive array와 다름.

## 7. 오답을 줄이는 경계 조건

| 문제 | 실수 | 테스트 |
| --- | --- | --- |
| 빈 입력 | 인덱스 접근 | N=0 |
| 원소 하나 | 양끝 포인터가 겹침 | N=1 |
| 모두 동일 | 해시 중복 | 같은 값 반복 |
| 음수 포함 | 비음수 전제 | -1, 0, 1 |
| 매우 큰 값 | 정수 overflow(C++) | 최대값 |
| 이미 정렬 | 알고리즘 최선/최악 | 오름·내림 |

## 8. 풀이 기록 형식

각 문제에 `문제 해석 → 처음 선택한 구조 → 시간/공간 복잡도 → 반례 → 수정한 이유 → 다시 풀 날짜`를 남긴다. 남의 풀이를 외우는 것보다 왜 특정 구조가 필요한지 설명할 수 있어야 한다.
